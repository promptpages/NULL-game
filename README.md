# NULL

A first-person 3D action campaign about a man raised from birth to be an assassin, whose father is murdered by an organisation called **Nook** when he is sixteen.

**Play:** open **`NULL-fullscreen.html`** (standalone) or **`index.html`** for the modular build.

---

## Latest improvements

### 2026-11-02 (handling / characters / enemies)
- **Weapon swap animation** — gun lowers, swaps mesh, rises again when you pick up a new weapon.
- **Bullets** — bright elongated tracers instead of pebble-like sparks.
- **NPC weapon grip** — weapons sit in the right hand and point forward.
- **Less blocky characters** — spheres/cylinders for heads, limbs, and torsos.
- **New weapons** — revolver, ARX carbine, combat shotgun, RPK LMG.
- **New enemy types** — Elite, Sniper, Juggernaut (rare/tough), Boss/Commander on later missions with better drops.

### Earlier pass
- Cutscene letterbox/vignette/FOV/lighting
- Spawns pushed out of crates/buildings
- CS-style ADS, dynamic crosshair, denser gun meshes, muzzle flash

## Controls

| Key | Action |
|---|---|
| **W A S D** | Move |
| **Shift** | Sprint |
| **C** | Crouch |
| **Ctrl** (while sprinting) | Slide |
| **Space** | Jump |
| **LMB** | Fire |
| **RMB** | Aim down sights |
| **R** | Reload |
| **V** | Melee |
| **E** | Interact / rob |
| **Tab** | Pause |
| **Esc** | Skip cutscene |
