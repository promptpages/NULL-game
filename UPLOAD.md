# Enable the full game on GitHub Pages

1. Download **null-game.js** from the project artifacts (self-extracting full campaign, ~60 KB).
2. Open this repo on GitHub → **js/** folder.
3. **Add file → Upload files** → choose `null-game.js` → commit (overwrite existing).
4. Wait 1–2 minutes, then hard-refresh https://promptpages.github.io/NULL-game/

## Standalone offline play

Open **NULL-fullscreen.html** in Chrome/Firefox/Edge. No upload needed — the whole game is inside that one file.
