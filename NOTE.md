The full game files (especially the large null-standalone.html and the js/ modules) are in the original zip. Please download the zip from the chat and upload the remaining files via the GitHub web UI (Add file > Upload files) or via git push from your machine.

Once files are up, go to Settings > Pages > Source: Deploy from a branch > main / (root) > Save.

Then the game will be at: https://promptpages.github.io/NULL-game/
